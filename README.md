# AMARDEV — Site de l'association

Page d'accueil de l'association AMARDEV, au service des personnes non-voyantes et malvoyantes.

## Accessibilité

Le site est conçu selon les critères WCAG (niveau AAA visé pour les contrastes) :

- Police **Atkinson Hyperlegible** (conçue pour la basse vision), taille de base 20 px
- Barre d'outils : agrandissement du texte (A− / A+), mode contraste élevé, lecture audio de la page (synthèse vocale fr-FR)
- HTML sémantique, lien d'évitement, focus clavier visible, compatible lecteurs d'écran (NVDA, JAWS, VoiceOver)
- Aucune dépendance : un seul fichier `index.html`, logo intégré en base64

## Déploiement

Site statique — hébergeable sur GitHub Pages : *Settings → Pages → Branch: main → / (root)*.
